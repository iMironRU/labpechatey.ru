# Макеты печатей: как готовить в Illustrator и сдавать в SVG

Шаблон печати для сайта — это не картинка, а **форма**: мы подставляем в неё
реквизиты клиента и прямо в браузере меряем, помещается ли текст. Поэтому от
макета нужны не только линии, но и понятные «места под текст» с известными
именами.

Ниже — всё, что для этого нужно. Если коротко: рисуем в миллиметрах, текст
оставляем живым, каждому полю даём имя из словаря, экспортируем SVG с
презентационными атрибутами и именами объектов.

---

## 1. Документ

| Параметр | Значение |
|---|---|
| Единицы | миллиметры (Файл → Параметры документа → Единицы: Миллиметры) |
| Цветовой режим | RGB |
| Монтажная область | квадрат, сторона = диаметр оттиска + 2 мм (для Ø40 → 42×42 мм) |
| Центр оттиска | ровно в центре монтажной области |
| Растр | не использовать вовсе |

Оттиск рисуем в размер: Ø40 мм на макете = Ø40 мм на бумаге. Поле в 1 мм по
краю нужно, чтобы толстая внешняя обводка не обрезалась.

---

## 2. Что можно рисовать

- окружности, дуги, прямые, произвольные контуры — обводкой;
- живой текст (не в кривых) — только в полях, см. раздел 4;
- микротекст по кольцу — тоже живой текст на дуге.

**Нельзя:** растровые эффекты, тени, градиенты, прозрачность, режимы
наложения, обтравочные маски, пунктир с нестандартным профилем, кисти, узоры.
Всё это либо не переживёт экспорт, либо не воспроизведётся на лазере.

**Цвет.** Всё рисуем одним плоским цветом — чёрным. На сайте цвет подменяется
(`currentColor`), поэтому любой другой цвет всё равно будет заменён, а
полупрозрачные заливки только запутают.

**Толщины.** Минимальная линия — 0.15 мм, иначе не проявится при травлении.
Внешнее кольцо обычно 0.4–0.55 мм.

---

## 3. Размеры текста

| Что | Минимум | Обычно |
|---|---|---|
| Основной текст (дуги, строки в центре) | **1.8 мм** | 1.9–2.2 мм |
| Микротекст по кольцу | 0.5 мм | 0.6–0.8 мм |
| Зазор от буквы до рамки | **0.9 мм** | 1.0–1.2 мм |

Зазор считается по самой высокой букве — «Й», «Ё», кавычки-ёлочки выше
прописных. Если по макету буквы почти касаются кольца, на оттиске они сольются
с ним.

Шрифт — **PT Sans Regular** (у нас им считается ёмкость полей). Другой шрифт
возможен, но его нужно согласовать заранее и приложить файл: движок меряет
ширину строки по метрикам шрифта, и подмена ломает подбор макетов.

---

## 4. Поля: имена и структура

Имя объекта в Illustrator становится `id` в SVG. Это и есть договор между
макетом и кодом.

### Группы

| Имя группы | Что внутри |
|---|---|
| `f_<ключ>` | **поле**: один текстовый объект, куда подставятся данные |
| `b_<ключ>` | **базовая линия** поля-дуги: открытый контур, по которому идёт текст |
| `s_<что угодно>` | статика: рамка, микротекст, звёздочки, герб — всё, что не меняется |

### Словарь ключей

Ключи конечны — движок знает только их:

| Ключ | Что подставляется |
|---|---|
| `name` | полное наименование организации |
| `name_2` | продолжение наименования, если оно идёт по второй дуге |
| `name_short` | краткое наименование («ООО «Ромашка»») |
| `fio` | ФИО предпринимателя или врача |
| `label_ip` | надпись «Индивидуальный предприниматель» |
| `label_ooo` | надпись с организационно-правовой формой («Общество с ограниченной ответственностью») |
| `name_bare` | наименование без формы, в кавычках («Ромашка») |
| `inn` | ИНН |
| `ogrn` | ОГРН или ОГРНИП |
| `kpp` | КПП |
| `city` | город |
| `address` | адрес |
| `position` | должность |
| `speciality` | специальность врача |
| `license` | номер лицензии |

Нужен ключ, которого нет в списке, — скажите, добавим вместе с обработкой.
Самовольное имя движок просто проигнорирует, и поле останется пустым.

### Текст по дуге

1. Рисуем дугу инструментом «Дуга» или из окружности («Ножницы» в нужных точках).
2. Дугу называем `b_<ключ>` — например `b_name`.
3. Инструментом «Текст по контуру» кладём на неё текст, группу называем `f_<ключ>`.
4. Внутри `f_*` должен быть **один** текстовый объект, без вложенных групп.

**Важно про дуги больше половины окружности.** Если дуга длиннее 180°, режьте
её на две части (добавьте опорную точку в самой верхней или самой нижней
точке). Иначе в SVG остаётся одна команда `A`, у которой два подходящих центра,
и браузер выбирает не тот — текст уезжает за край оттиска. Мы на этом уже
обожглись.

Направление важно: верхняя дуга рисуется слева направо через верх, нижняя —
слева направо через низ (тогда текст внизу читается нормально, а не вверх
ногами).

### Текст строкой

Обычный текстовый объект с выключкой по центру, `x = 0`. Группу называем
`f_<ключ>`. Базовая линия `b_*` для него не нужна.

---

## 5. Что подставит движок

- Текст в полях **заменяется целиком** — то, что вы напишете в макете, видно
  только вам. Пишите осмысленную рыбу нужной длины: она помогает проверить
  вёрстку.
- Регистр приводится к верхнему (это настройка шаблона, её можно поменять).
- Если строка не помещается, движок сначала уменьшает кегль до минимального,
  потом слегка поджимает межбуквенное, и только потом помечает макет как
  неподходящий. Поэтому оставляйте в поле запас — макет, который «впритык» на
  вашей рыбе, у половины клиентов не сработает.
- Поле, для которого нет данных, удаляется целиком. Макет от этого не должен
  разваливаться: не стройте композицию на обязательном присутствии всех полей.

## 6. Экспорт из Illustrator

**Файл → Экспортировать → Экспортировать как… → SVG**, затем в диалоге:

| Настройка | Значение |
|---|---|
| Стилизация (Styling) | **Presentation Attributes** |
| Шрифт (Font) | **SVG** — текст остаётся живым |
| Изображения (Images) | Preserve (их и не должно быть) |
| Object IDs | **Layer Names** — иначе имена полей потеряются |
| Decimal | 2 |
| Minify | выключено |
| Responsive | **выключено** — нужен фиксированный `viewBox` |

Не используйте «Сохранить как → SVG»: там другой набор опций и обычно
появляются `<style>` с классами, из-за которых мы теряем цвет и имена.

### Самопроверка перед отправкой

Откройте экспортированный файл в текстовом редакторе и убедитесь:

- есть `viewBox` и он квадратный, размеры в мм совпадают с монтажной областью;
- встречаются `id="f_…"`, `id="b_…"`, `id="s_…"` — ровно с теми ключами;
- внутри `f_*` есть `<text>`, а не `<path>` (если `<path>` — текст перевели в кривые);
- нет `<image>`, `<filter>`, `clip-path`, `opacity`, `<style>`;
- цвет один и тот же у всех линий.

## 7. Как мы работаем: что от кого

Короткая версия: **дизайнер живёт в Illustrator, шаблон собираем мы**.
Своими руками наш SVG он не делает и не открывает — Illustrator текст по
контуру в SVG не умеет ни прочитать, ни записать: при открытии сводит
(«Текст по контуру будет сведен»), при экспорте разбирает на отдельные
буквы. Это его ограничение, обойти нельзя.

### Дизайнер присылает

1. **Исходник `.ai`** — рабочий файл, текст живой, по контуру.
2. **`.svg` из того же файла** — File → Export → Export As → SVG,
   настройки из раздела 6. Экспорт нужен как сырьё для конвертера, сам по
   себе он в дело не идёт.
3. Строку описания: для кого раскладка (ИП, ООО, врач) и как её называть
   клиенту («Стандарт ГОСТ», «Компактный»).

### Проверить себя до отправки

На сайте есть страница приёмки: **/dizajner**. Перетащите туда
SVG-экспорт — она разберёт разметку, покажет список замечаний (единицы,
имена полей, цвет классами, многострочные поля), соберёт шаблон и тут же
примерит на нём настоящие реквизиты: ООО «Ромашка», ИНН из 10 цифр, ОГРН
из 13. Сразу видно, что не влезает.

Файл никуда не отправляется — всё считается у вас в браузере. Готовый
шаблон можно скачать кнопкой и приложить к письму, но это не обязательно:
мы собираем его сами.

### Мы делаем

    python3 scripts/convert_designer_svg.py путь/до/макета.svg

Скрипт переводит координаты в миллиметры, ставит центр в 0,0,
восстанавливает дуги по положению букв, собирает поля и метаданные.
Дальше `scripts/index_templates.py` считает ёмкость, и шаблон едет в
`public/templates/`.

### Что проверяем и с чем возвращаемся

Мы подставляем в шаблон настоящие реквизиты — длинные наименования, ИНН
из 12 цифр, ОГРНИП из 15 — и смотрим, что не влезло. Возвращаемся с
конкретикой: «ОГРН при 1.8 мм шире поля на 2 мм, нужно поднять диаметр
или раздвинуть строки». Дизайнер правит `.ai` и присылает заново —
конвертация повторяется одной командой.

### Правки

Правятся всегда в `.ai`. Наш SVG — производное, его переписывает
конвертер при каждом прогоне, так что менять его руками бессмысленно.

## 8. Что приложить к макету

1. SVG по правилам выше.
2. Одну строку описания: название раскладки, как её показывать клиенту
   («Стандарт ГОСТ», «Компактный»), и для кого она — ИП, ООО, врач.
3. Если поле нестандартное (например, две дуги под наименование) — короткая
   записка, что куда ложится.

Метаданные (диаметр, кегли, минимумы, ёмкость) мы проставляем сами: ёмкость
считается скриптом по геометрии и метрикам шрифта, чтобы она не расходилась с
разметкой. Скрипты лежат в `scripts/make_templates.py` и
`scripts/index_templates.py`, готовые шаблоны — в `public/templates/`.

## 9. Разбор присланного макета O_01

Первый файл от дизайнера (`O_01.ai` / `O_01.svg`) лежит рядом переведённым
в наш формат: [образец-шаблона-O_01.svg](образец-шаблона-O_01.svg). Рисунок
не менялся — кольца, звёзды и композиция те же. Что пришлось переделать:

| В присланном файле | В образце |
|---|---|
| единицы в пунктах, центр в углу (`viewBox 0 0 116.47`) | миллиметры, центр 0,0, Ø38 |
| `f_<tip>`, `f_<region>` — угловые скобки в имени | `f_label_ooo`, `f_city` |
| ключи `tip`, `region`, `name` | `label_ooo`, `city`, `name_bare` из словаря |
| текст по дуге разобран на 40 отдельных букв | одна строка на `textPath` с базовой дугой `b_name` |
| цвет классами в `<style>` | `fill="currentColor"` атрибутом |
| текст сжат по горизонтали `scale(.85 1)` | без сжатия |

Геометрию дуг восстановил по положению букв: через точки их привязки
провёл окружность — получилось 15.14 мм для верхней дуги (размах 210°) и
16.90 мм для нижней (56°). Скрипт перевода —
[scripts/convert_designer_svg.py](../scripts/convert_designer_svg.py), но
это разовая мера: следующие макеты проще сразу отдавать по правилам выше.

**Что вскрылось на данных.** С PT Sans и без горизонтального сжатия строка
«ОГРН 1105658001239» шире, чем место под неё в этой раскладке, — она
наезжает на звёздочки. Варианты: отдать нам шрифт Pragmatica, поднять
диаметр до 40 мм или раздвинуть центральные строки.

## 10. Частые ошибки

| Симптом на сайте | Причина в макете |
|---|---|
| Поле пустое, текста нет | группа названа не по словарю или текст в кривых |
| Текст уехал за край оттиска | дуга длиннее 180° одной командой `A` |
| Текст внизу читается вверх ногами | нижняя дуга нарисована в обратную сторону |
| Буквы липнут к кольцу | зазор меньше 0.9 мм |
| Макет всегда «не подходит» | в поле нет запаса: рыба в макете короче реальных данных |
| Оттиск не перекрашивается | цвет задан стилем `<style>`, а не атрибутом |
