# Лаборатория печатей — конструктор печати

Онлайн-конструктор печатей для ИП и ООО: реквизиты по ИНН, подбор макета под
длину наименования, выбор оснастки и оформление заказа.

## Запуск

```bash
npm ci
npm run dev
```

Открыть <http://localhost:3000>.

## Стек

Next.js 16 (App Router, `output: "export"`), React 19, TypeScript, Tailwind 4.
Сервера нет: `npm run build` даёт папку `out/`, которая целиком отдаётся статикой.

| Путь | Что это |
|---|---|
| `app/page.tsx` | экран конструктора: тип печати, реквизиты, превью, оснастки, цена |
| `components/Checkout.tsx` | экран оформления заказа: получение, оплата, сводка |
| `components/StampPreview.tsx` | живое превью: подбор и подстановка данных в шаблоны |
| `lib/stamp.ts` | движок шаблонов: измерение текста, подбор по длине, подстановка |
| `lib/inn.ts` | контрольные цифры ИНН и ОГРН, мок поиска по реестру |
| `content/*.json` | все тексты; в разметке литералов нет |
| `public/templates/` | шаблоны печатей в SVG и их индекс |
| `design-ref/` | хендофф дизайнера: README и прототипы |

## Шаблоны печати

Шаблон — SVG с фиксированной геометрией: группа `f_<ключ>` это поле,
путь `b_<ключ>` — его базовая линия, `s_*` — статика. Параметры полей лежат
в метаданных внутри файла, вместимость считается из геометрии по метрикам
шрифта. Подробности формата и требования к печатям — в репозитории
`seal-constructor` (`docs/template-spec.md`, `docs/seal-requirements.md`).

Подбор макета идёт по фактической длине текста: варианты, куда реквизиты не
влезают, не показываются вовсе.

## Поиск по ИНН

Сейчас мок: задержка 850 мс, ИНН `5610100200` отдаёт «не найдено».
В проде на его место встаёт DaData или API ФНС — запрос через прокси,
ключ на статический клиент не кладётся.

## Деплой

GitHub Actions → GitHub Pages, воркфлоу `.github/workflows/deploy.yml`.
Пуш в `main`: `npm ci` → `npm run build` → `out/.nojekyll` → публикация.
Сайт живёт в подпапке, поэтому сборке передаётся `NEXT_PUBLIC_BASE_PATH`.
